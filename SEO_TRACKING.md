# AntZ Music — Search Console tracking

This is a measurement checklist, not a claim of improved search rankings.

## Setup after publishing
1. Open Google Search Console for the **https://antzmusic.com/** property or the domain property.
2. In **Sitemaps**, submit **sitemap.xml**.
3. Inspect these URLs and request indexing if useful:
   - https://antzmusic.com/
   - https://antzmusic.com/piano-guitar-lessons-ealing.html
   - https://antzmusic.com/live-music-bookings-london.html
   - https://antzmusic.com/live-looping-performances.html
4. Verify the pages actually load in a browser and that contact links work.

## Baseline (record after Search Console starts showing data)
Record each page's **impressions**, **clicks**, **CTR**, **average position**, and **indexing state**.
Do not invent missing data or treat a zero in a new property as a measured zero.

## Outcome metrics
Track *qualified enquiries* separately from visitors:
- Lesson enquiries and actual new students.
- Gig enquiries and paid bookings.
- Sessions or collaboration requests.
Record how each enquiry found AntZ Music when practical.

## Review
Review around **18 November 2026**, comparing a consistent date window in Search Console once data is available. Expect some delay in indexing and reporting. Refine content based on relevant queries, not mass-generated keyword articles.
